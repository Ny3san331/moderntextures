# moderntextures

Packs de resource pack do servidor e documentação do projeto **FixTextures** (antigo ModernTextures).

- Site dos packs: <https://ny3san331.github.io/moderntextures/>
- Plugin: Paper 26.3 / Java 25, com ViaVersion/ViaBackwards para clientes antigos.
- Os arquivos `.zip` na raiz são servidos diretamente para os jogadores.
- **Não renomeie nem apague** um ZIP publicado sem atualizar o `manifest.json` do plugin.

## Publicar um pack

1. Gere o ZIP e o `manifest.json`.
2. Envie os dois para a raiz deste repositório.
3. Aguarde o GitHub Pages publicar (1–3 min).
4. Teste a URL direta no navegador.
5. Atualize o manifesto em `plugins/FixTextures/` e rode `/ft reload`.

Detalhes em [docs/TUTORIAL-TEXTURAS.md](docs/TUTORIAL-TEXTURAS.md).
